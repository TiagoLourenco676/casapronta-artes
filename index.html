Gerador de artes de divulgação para WhatsApp · Equipe comercial

Este visualizador não ativou o gerador.Abra o link do site no Safari ou Chrome, fora da prévia de arquivos do celular. Se o aviso continuar aparecendo, verifique se o GitHub Pages foi ativado. A arte só pode ser personalizada com o gerador ativo.

1 Número de atendimento

Digite o número com DDD. Ex.: (48) 99999-9999. O +55 é opcional.
Abra no navegador para ativar

2 Escolha e confira a arte

Prévia aguardando navegador compatível. Não compartilhe esta imagem sem inserir seu WhatsApp.
Imagem horizontal · ideal para enviar em conversas ou statusO número aparece aqui automaticamente

3 Como usar

Digite o seu número com DDD (11 dígitos) e confira a prévia. Toque em Compartilhar imagem para enviá-la pelo WhatsApp ou em Salvar imagem PNG para guardá-la na galeria/Arquivos. Depois, se quiser, escolha o outro modelo e repita. O QR Code acompanha automaticamente o número informado.
Uso da equipe comercial CasaPronta. Este arquivo funciona sem internet e não envia os números para nenhum servidor. O contato usado fica salvo apenas neste navegador quando o armazenamento é permitido. Para usar no iPhone com todas as funções, abra a página em um navegador compatível, não em uma prévia de arquivo.
